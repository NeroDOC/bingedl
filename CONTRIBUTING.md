# Contributing

- One script, `bingedl`: logic in functions, `main` runs only when executed.
- Must work on macOS bash 3.2: no `set -u`, associative arrays, `mapfile`, `${var,,}`, `wait -n`.
- DRM is detected and reported, never circumvented; PRs that add circumvention are declined.
- Before opening a PR (needs ffmpeg and ffprobe; `scripts/fetch-ffmpeg.sh DIR` downloads them):

```sh
bash tests/selftest.sh
bash tests/e2e.sh
shellcheck -x bingedl tests/*.sh scripts/*.sh
```

- Commit messages follow [Conventional Commits](https://www.conventionalcommits.org/)
  (`feat:`, `fix:`, `docs:`, `test:`, `ci:` ...).
- Commit messages and PR titles follow [Conventional Commits 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/);
  PRs are squash-merged, so the PR title becomes the commit (a CI check enforces it).
- `CHANGELOG.md` ([Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/)) and `VERSION` are generated by the
  Release workflow (git-cliff, see `cliff.toml`): don't edit them by hand.
  `feat` -> Added, `fix` -> Fixed, `perf`/`refactor` -> Changed, `revert` -> Removed, `deprecate` -> Deprecated,
  `security` -> Security; `docs`/`test`/`ci`/`build`/`chore`/`style` stay out of the changelog.
  `!` or a `BREAKING CHANGE:` footer bumps the major version.
